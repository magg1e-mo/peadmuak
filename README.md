# เปิดหมวก

แอปขอเพลงและรับทิปสำหรับเล่นดนตรีเปิดหมวก

- `index.html` หน้าคนดู (ลิงก์ที่อยู่ใน QR)
- `performer.html` หน้าคนเล่น (ล็อกอิน Google)
- `qr.html` ป้าย QR สำหรับพิมพ์ติดกล่องหมวก

## แก้ไขเองได้
- ลิสต์เพลง: `js/songs.js`
- เบอร์ PromptPay, ชื่อบนเวที, สถานที่เล่น, ปุ่มยอดทิป: `js/config.js`

แก้แล้วอัปไฟล์นั้นขึ้น GitHub ทับของเดิม เว็บจะอัปเดตเองในไม่กี่นาที

## วิธีใช้ตอนเล่น
1. เปิดหน้าคนเล่น เลือกสถานที่ กด "เริ่มรอบเล่น"
2. คนดูสแกน QR ขอเพลงได้ คำขอเด้งขึ้นคิวทันที
3. ได้เงินสดกดปุ่ม +10 / +20 / +50 / +100 (เลือก "เงินสด" หรือ "โอน" ก่อน)
4. ทิปโอนที่คนดูแจ้งมา จะอยู่ในกล่อง "ทิปรอเช็คยอด" เทียบเศษสตางค์กับแจ้งเตือนธนาคาร แล้วกด "ยอดเข้าแล้ว"
5. เลิกเล่นกด "จบรอบ"

หมายเหตุ: ระบบไม่ได้เชื่อมกับธนาคาร ยอดโอนที่คนดูแจ้งเป็นแค่การแจ้ง ต้องเช็คกับแอปธนาคารก่อนกดยืนยันเสมอ
